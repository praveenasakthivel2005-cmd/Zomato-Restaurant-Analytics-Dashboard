# Zomato Restaurant Analytics Dashboard using Power BI

## Project Overview
This project analyzes Zomato restaurant data using Microsoft Power BI to understand restaurant distribution, ratings, customer votes, pricing, online delivery, and geographic performance.

The dashboard provides interactive visualizations and insights to support data-driven decision-making.

## Objectives
- Analyze restaurant distribution across cities.
- Understand restaurant ratings and customer voting patterns.
- Compare restaurant counts across price ranges.
- Analyze online delivery and table booking availability.
- Explore cuisine preferences and geographic performance.
- Build an interactive dashboard using Power BI.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Cleaning and Transformation
- Data Visualization
